# Skill Install

이 저장소의 스킬을 `~/.claude/skills/<이름>`에 **심볼릭 링크**로 연결하는 스킬이다.

복사가 아니라 링크를 쓰는 이유는, 저장소에서 스킬을 고치면 다시 설치하지 않아도 바로 반영되게 하기 위해서다. 복사하면 두 곳의 내용이 쉽게 어긋난다. 그래서 다시 설치가 필요한 경우는 스킬을 새로 만들거나 이름을 바꿨을 때뿐이다.

## 한눈에 보기

| 작업 | 언제 | 하는 일 |
| --- | --- | --- |
| 상태 확인 | 모든 작업의 첫 단계, "설치 상태 보여줘" | 스킬마다 상태를 분류하고 끊어진 링크를 찾는다 |
| 설치 | "스킬 설치해줘", "<이름>만 설치해줘" | 검사 통과한 스킬을 링크한다. 지정이 없으면 전부 |
| 교체 | 상태가 `다른 링크`나 `충돌`일 때 | 확인을 받고 기존 것을 백업한 뒤 링크한다 |
| 제거 | "<이름> 설치 해제" | 이 저장소를 가리키는 링크만 지운다 |
| 끊어진 링크 정리 | 스킬 이름을 바꾸거나 지운 뒤 | 확인을 받고 링크만 지운다 |

명령은 `references/commands.md`에 있다.

## 경로

| 이름 | 값 |
| --- | --- |
| 저장소 (`REPO`) | 이 스킬 원본이 있는 저장소의 루트 (링크를 거쳐 실행될 수 있어 실제 경로로 구한다) |
| 설치 폴더 (`DEST`) | `~/.claude/skills` (그 자체가 다른 폴더를 가리키는 링크일 수 있다) |
| 백업 폴더 (`BACKUP`) | `~/.claude/skills-backup` |

**설치 대상**은 `REPO` 바로 아래에서 `SKILL.md`를 가진 폴더다. 폴더 이름이 곧 스킬 이름이다. 숨김 폴더(`.claude/`, `.git/` 등)는 제외한다.

**이 스킬의 위치**: 원본은 저장소 루트의 `skill-install/`이고 자기 자신도 설치 대상이다. 저장소의 `.claude/skills/skill-install`은 원본을 가리키는 상대 링크(`../../skill-install`)라서, 전역 설치 전에도 이 저장소에서는 바로 쓸 수 있다.

## 상태 분류

| 상태 | 조건 | 처리 |
| --- | --- | --- |
| `미설치` | 경로가 없음 | 바로 링크 |
| `설치됨` | 링크이고 `REPO/<이름>`을 가리킴 | 건너뜀 |
| `다른 링크` | 링크이지만 다른 곳을 가리킴 | "교체" |
| `충돌` | 실제 폴더나 파일이 있음 | "교체" |
| 끊어진 링크 | `DEST`의 링크가 `REPO` 안을 가리키지만 대상이 없음 | "끊어진 링크 정리" |

결과는 `| 스킬 | 상태 | 검사 |` 표로 보여 준다. "상태 보여줘" 요청이면 여기서 끝낸다.

## 작업 흐름

1. **상태 확인**: 위 분류대로 표를 만든다.
2. **검사**: 설치할 스킬의 `SKILL.md`가 `---`로 시작하고 닫히는지, `name`이 폴더 이름과 같은지, `description`이 있는지 본다. 잘못된 스킬은 Claude Code가 인식하지 못하거나 엉뚱하게 실행하므로, 실패하면 설치하지 않고 이유를 알린 뒤 고칠지 묻는다.
3. **설치**: `미설치`는 절대 경로 링크를 만든다.
4. **교체**: `다른 링크`나 `충돌`은 바로 바꾸지 않는다. 사용자가 따로 쓰던 스킬일 수 있기 때문이다.
   - 무엇이 있는지 보여 준다(실제 폴더면 `description` 첫 줄과 파일 목록).
   - 스킬마다 교체할지 답을 받는다.
   - `충돌`이면 기존 폴더를 `$BACKUP/<이름>-<YYYYmmdd-HHMMSS>`로 옮긴 뒤 링크한다. 지우지 않고 옮겨야 되돌릴 수 있다.
   - 사용자가 백업 없이 지우라고 하면, 지우기 전에 되살릴 방법이 있는지(예: `DEST`의 git에 커밋되어 있는지) 확인해 알려 준 뒤 지운다.
   - `다른 링크`면 링크만 지우고 새로 링크한다. 가리키던 원본은 그대로 남는다.
5. **제거**: `설치됨`일 때만 링크를 지운다. 실제 폴더나 다른 곳을 가리키는 링크는 이 스킬이 설치한 것이 아니므로 지우지 않고 알린다. 백업 폴더에 같은 이름이 있으면 되돌릴지 묻는다.
6. **끊어진 링크 정리**: 목록을 보여 주고 지울지 묻는다.

지우는 명령은 변수 대신 절대 경로를 적는다. 변수로 만든 경로는 Claude Code 안전 검사에 막히고, 링크에 `-r`이나 끝 `/`를 붙이면 원본이 지워진다(`references/commands.md` "지우기").

## 결과 보고

작업이 끝나면 상태 확인을 다시 실행해 최종 표를 보여 주고 덧붙인다.

- 새로 설치, 교체, 제거한 스킬과 정리한 끊어진 링크
- 백업한 폴더 경로
- 검사에 실패해 건너뛴 스킬과 이유
- `DEST`가 git 저장소라면 그 저장소에 변경이 생겼다는 사실
- 새 스킬은 새로 시작한 Claude Code 세션부터 확실히 반영된다는 안내

## 하지 않는 일

- 이 저장소에 같은 이름의 스킬이 없는 항목(다른 곳에서 설치한 스킬) 만들기·옮기기·지우기
- `synced/`(Claude 앱이 동기화용으로 관리하는 폴더), `.git/`, `.gitignore`, `README.md` 등 스킬 폴더가 아닌 항목 건드리기
- `DEST`의 git 상태 바꾸기(커밋, 되돌리기, `.gitignore` 수정). 변경이 생겼다는 사실만 알린다
- 확인 없이 `다른 링크`·`충돌` 교체, 끊어진 링크 삭제
