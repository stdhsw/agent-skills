# ⌨️ 단축키·명령어 가이드

> **표기 규칙**
>
> | 표기 | 의미 |
> | --- | --- |
> | `A + B` | A와 B를 동시에 누릅니다 |
> | `A → B` | A를 누르고 손을 뗀 뒤 B를 누릅니다 (코드 키) |
> | ⚙️ | 기본값이 아니라 직접 설정한 단축키입니다 |
>
> `Cmd`, `Opt`, `Ctrl`, `Shift`는 맥 키보드 기준입니다. VSCode 문서의 `Alt`는 맥의 `Opt`입니다.

---

## 🤖 Claude Code 명령어

### 💬 세션 · 설정

| 명령어 | 설명 |
| --- | --- |
| `/resume` | 현재 프로젝트의 이전 세션 목록을 보고 골라서 이어 가기 |
| `/usage` | 요금제 사용량과 남은 한도 확인 |
| `/effort` | 응답의 추론 수준 변경 (low / medium / high 등) |
| `claude -r` | 터미널에서 실행할 때 세션 목록을 보고 골라서 이어 가기 |
| `claude -c` | 터미널에서 실행할 때 가장 최근 세션을 바로 이어 가기 |

### 🧹 대화 · 컨텍스트 관리

> 💡 대화가 길어지면 응답이 느려지고 사용량이 빨리 줄어듭니다. 주제가 바뀌거나 대화가 길어지면 정리합니다.

| 명령어 | 설명 |
| --- | --- |
| `/clear` | 대화 내용을 비우고 새로 시작 (주제가 바뀔 때) |
| `/compact` | 지금까지의 대화를 요약해 컨텍스트 줄이기 |
| `/context` | 현재 컨텍스트를 얼마나 쓰고 있는지 확인 |
| `/rewind` | 이전 시점으로 대화와 파일 변경을 되돌리기 |

## 💻 VSCode 단축키

### 🖱️ 멀티 커서

| 단축키 | 설명 |
| --- | --- |
| `Opt + 클릭` | 클릭한 위치에 커서 추가 |
| `Cmd + Opt + ↑ / ↓` | 위 / 아래 줄에 커서 추가 |
| `Cmd + D` | 선택한 단어와 같은 다음 단어에 커서 하나씩 추가 |
| `Cmd + Shift + L` | 선택한 단어와 같은 모든 단어에 커서 한꺼번에 추가 |

### 🪟 창 · 그룹 · 사이드바

| 단축키 | 설명 |
| --- | --- |
| `Cmd + B` | 사이드바 열기 / 닫기 |
| `Cmd + J` | 하단 패널 열기 / 닫기 |
| `Cmd + 0` | 사이드바로 포커스 이동 |
| `Cmd + 1 ~ 9` | 1 ~ 9번 편집기 그룹으로 포커스 이동 |
| ⚙️ `Cmd + K → Cmd + N` | 현재 편집기를 새 창으로 이동 |
| ⚙️ `Cmd + Shift + ]` | 다음 사이드바 보기로 이동 |
| ⚙️ `Cmd + Shift + [` | 이전 사이드바 보기로 이동 |

### 🖥️ 터미널

| 단축키 | 설명 |
| --- | --- |
| `` Ctrl + ` `` | 터미널 열기 / 닫기 |
| `` Ctrl + Shift + ` `` | 새 터미널 만들기 |
| `Cmd + Shift + C` | 외부 터미널 앱을 새 창으로 열기 |
| `Cmd + Ctrl + ↑ / ↓` | 터미널 패널 크기 늘리기 / 줄이기 |

### ✍️ 코드 작성

| 단축키 | 설명 |
| --- | --- |
| `F12` | 정의로 이동 |
| `Opt + F12` | 정의 미리 보기 (현재 화면에서 펼쳐 보기) |
| `Opt + Shift + F12` | 모든 참조 찾기 |
| `Ctrl + Space` | 자동 완성 제안 띄우기 |
| `Cmd + K → Cmd + I` | 호버 정보 표시 (변수 타입, 문서) |
| `Cmd + K → Cmd + F` | 선택한 영역 코드 정렬 |
| ⚙️ `Ctrl + Shift + U` | 선택한 글자를 대문자로 |
| ⚙️ `Ctrl + Shift + L` | 선택한 글자를 소문자로 |

### 💾 저장 · 종료

| 단축키 | 설명 |
| --- | --- |
| ⚙️ `Cmd + Opt + S` | 열린 파일 모두 저장 |
| ⚙️ `Cmd + Q → Cmd + Q` | VS Code 종료 (두 번 눌러야 종료되어 실수 방지) |

### 🐞 디버깅

| 단축키 | 설명 |
| --- | --- |
| `F5` | 디버그 시작 / 계속 |
| `Shift + F5` | 디버그 중지 |
| `F9` | 중단점 설정 / 해제 |
| `F10` | 다음 줄 실행 (함수 안으로 들어가지 않음) |
| `F11` | 함수 안으로 들어가기 |
| `Shift + F11` | 현재 함수에서 빠져나오기 |
| `Cmd + ; → Cmd + C` | 커서 위치의 유닛 테스트 디버그 실행 |
